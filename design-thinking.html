Design Thinking Process

This page explains how I applied design thinking principles to create this portfolio website. The design thinking process helped me understand user needs and create a meaningful digital experience.

1

Empathize

I started by understanding who would visit my portfolio: potential employers, collaborators, and peers. I researched what makes an effective portfolio and what information is most important to showcase.

2

Define

I defined the core problem: How can I create a portfolio that effectively showcases my skills, projects, and personality while being easy to navigate and visually appealing?

3

Ideate

I brainstormed different design approaches, considering various layouts, color schemes, and interactive elements. I sketched wireframes and created mood boards to explore different visual directions.

4

Prototype

I built an initial version of the website with HTML, CSS, and basic interactivity. This prototype served as a functional mockup to test different ideas and gather feedback.

5

Test

I tested the website on different devices and browsers, checking navigation flow, performance, and accessibility. I gathered feedback from peers and made iterative improvements.

6

Iterate

Based on testing feedback, I refined the design, improved visual hierarchy, optimized performance, and enhanced user experience. This is an ongoing process as I continue to refine the site.

Key Design Decisions

  • Dark Theme: Chose a dark background for a modern, professional look that reduces eye strain and makes content stand out
  • Responsive Design: Ensured the website works seamlessly on desktop, tablet, and mobile devices
  • Clear Navigation: Kept navigation simple and intuitive so visitors can easily find information
  • Visual Hierarchy: Used typography, spacing, and color to guide users' attention to important content
  • Interactive Elements: Added JavaScript functionality to make the website engaging and interactive
  • Accessibility: Implemented semantic HTML and accessibility features to ensure everyone can use the site
