Accessibility

Accessibility Statement

I am committed to ensuring that this website is accessible to all visitors, including those with disabilities. This page outlines the accessibility features I've implemented and my commitment to web accessibility standards.

Our Commitment

I am dedicated to providing a website that is accessible to the widest possible audience, regardless of their abilities or the technology they use to access the web. I strive to meet or exceed the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards.

Accessibility Features Implemented

Semantic HTML

The website uses proper semantic HTML elements such as header, nav, main, section, article, and footer to structure content meaningfully.

Image Alt Text

All images include descriptive alternative text that conveys the meaning and purpose of the image to users with visual impairments.

Keyboard Navigation

The website is fully navigable using keyboard only. All interactive elements are accessible via Tab key and can be activated with Enter or Space.

Color Contrast

Text has sufficient color contrast ratios to meet WCAG standards, ensuring readability for users with low vision or color blindness.

Readable Typography

Font sizes are large enough for comfortable reading, and line spacing is adequate. Users can resize text without loss of functionality.

Responsive Design

The website is responsive and works well on all device sizes, from small mobile phones to large desktop screens.

Form Accessibility

All form inputs have associated labels, clear instructions, and helpful error messages to guide users through form completion.

Descriptive Links

Link text is descriptive and clearly indicates where the link leads, making it easy for screen reader users to understand.

No Auto-playing Content

Media does not auto-play, allowing users to control when audio or video content starts, which is important for users with cognitive disabilities.

Skip Navigation Links

Users can skip repetitive navigation elements using skip links, allowing quicker access to main content.

Screen Reader Support

This website has been tested with popular screen readers including NVDA and JAWS to ensure content is properly announced and navigable for users with visual impairments.

Browser Compatibility

The website works with modern browsers including Chrome, Firefox, Safari, and Edge. I've tested functionality across different browsers and platforms.

Feedback and Improvements

I welcome feedback on the accessibility of this website. If you encounter any accessibility barriers or have suggestions for improvement, please contact me. I'm committed to making this website as accessible as possible.
